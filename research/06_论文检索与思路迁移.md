### 簇 1：Drifting Models（生成建模 = 训练时分布演化）
| 论文 | 要点 |
|---|---|
| **Generative Modeling via Drifting**（主论文） | 生成建模 = **训练时**推前分布的动态演化；"漂移场"在生成分布=数据分布时**自然归零**（稳定平衡点）；损失 = 漂移场 L2 范数；**核化均值偏移**：真实数据样本吸引、生成样本排斥 |
| On the Wasserstein Gradient Flow Interpretation of Drifting Models | GMD 算法 = 找 **KL Wasserstein 梯度流的不动点**；用 **Parzen 平滑得分估计**替代不可计算的 score；实际实现 ≈ 去偏 Sinkhorn 散度上的 WGF |
| Gradient Flow Drifting / Kernel-Gradient Drifting / Companion-Elliptic Kernel | 理论补全簇：核族可识别性、Wasserstein 梯度流统一框架 |

## 二、GMD ↔ 我们的 ES：同构映射

| GMD（生成建模） | SDT-ES（参数优化） |
|---|---|
| 粒子云（生成样本）训练时演化 | θ ± σε 候选云，每 epoch 演化一步 |
| 漂移场 v(x) = 吸引(真) − 排斥(假) | 更新 = Σ z·ΔW：z>0 候选的 ΔW 吸引、z<0 反向 |
| Parzen 平滑得分估计 | z_n ε_n = fitness 景观 score 的蒙特卡洛估计（**全局 z-score = 单带宽 Parzen**） |
| 分布匹配 → 漂移场归零（平衡点） | 收敛 = 更新范数→0（我们现在用固定 epoch 数，**缺此监控**） |
| 核化均值偏移（样本级加权） | 权重固定为 z（线性）——**核化/softmax 加权未试** |
| 锚点：真实数据样本 | **零噪声锚点缺失**：我们用全局 μ 中心化，未扣"θ 自身 fitness" |

## 三、由检索直接导出的实验（按成本排序）

| # | 实验 | 机制来源 | 预期 |
|---|---|---|---|
| X1 | **零噪声锚点基线**：每 epoch 评一次当前 θ（无噪声）的平均 loglik b₀，z=(raw−b₀)/std 替代 (raw−μ)/std | GMD 吸引/排斥锚点 + EggRollBS 基线扣除（原始库有、我们未迁移） | 压掉"图像难度方差"对 z 的注入（协议角度 A 的算法面） |
| X2 | **核化对偶加权**：对偶对内差分权重 d_k = w(z₂ₖ) − w(z₂ₖ₊₁)，w = softmax(τ·z)，更新 Σ d_k·ε₂ₖ（保留 M1 精确性） | GMD 核化均值偏移 | 重尾 fitness 的离群鲁棒聚合 |
| X3 | **σ_slot 响应方差校准**：一次离线扫描每槽 Δfitness 方差，σ_slot ∝ 1/√Var_slot（等响应化） | Parzen 带宽自适应 + INES 坐标级步长 | 直接回应消融发现（深槽噪声污染共享 σ_z） |
| X4 | **漂移范数监控**：CSV 增列 ‖Σz·ΔW‖ | GMD 平衡点 | 收敛诊断/自然停止条件 |
| X5 | β 温度自适应：β ∝ std(raw)（WGF 温度耦合） | WGF 不动点理论 | 替代线性 β schedule |

注：ES-for-LLM 的多样性结论为"混合估计器净负（E2<SGD）"提供外部解释——分类任务要峰值精度，
ES 的生态位（多样性、无梯度场景）与之一致，此结论**升级为外部佐证**（见 04 修订声明）。

## 四、行动与结果

### X1 逐候选零噪声锚点（控制变量）——10ep 干净证伪

实现：`--baseline-zero`（每 epoch 无噪声前向算 b₀(x)，raw′=raw−b₀(x) 再 z-score；
`‖g‖` 漂移范数监控同步加入日志）。锚点口径与候选一致（同 relax/β/blocks/QAM 基值）。

| 臂 | best_val@10ep | 对照 | Δ |
|---|---|---|---|
| anchor 无QAM | 10.75% | 11.45% | −0.7pp |
| anchor + QAM ssa | 11.55% | 12.25% | −0.7pp |
| anchor + pair-shared + QAM ssa | **12.70%** | pair-shared 12.65% | +0.05pp（持平） |

结论：**单独使用为负向（超出单种子噪声带边缘），叠加 pair-shared 后无增益**；
锚点前向开销 ~8s/epoch（7.5→18.8s）。理论（无偏 + 方差缩减）未兑现，
可能机制：AdamW 每 epoch 单步对梯度尺度变化的瞬态敏感 + 10ep 判定窗口过短。
**记录为该配置下的干净负结果**；不排除 100ep 或配合 AdamW 外的 solver 有差异——
优先级降低，资源转向 X3（σ_slot 响应方差校准，消融发现的直接解药）。

方法论注：z-score 为仿射修正且 M1（ΣΔW≡0）成立，故**全局常数锚点无效**——
有效形式必须是逐候选（随图像变化）的减法，本实现即为该形式。

### 下一步（更新优先级）

1. **X3 σ_slot 响应方差校准**（等响应化，一次性离线扫描）——消融发现"深槽噪声污染共享 σ_z"的直接解药；
2. **X2 核化对偶加权**（对偶对内差分权重 d_k = w(z₂ₖ)−w(z₂ₖ₊₁)，保留 M1）；
3. pair-shared 100ep×3 种子确认（此前 10ep +0.4pp 唯一正收益协议杠杆）。
