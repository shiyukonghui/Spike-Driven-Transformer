## 一、原始库的算法规格（从代码提取，非文档转述）

### 1.1 EggRoll（`src/hyperscalees/noiser/eggroll.py`）的核心契约

```
thread_id p（每个 thread 评估一个样本）：
  true_thread_idx = p // 2          ← 相邻两个 thread 共享同一噪声 key
  sign = +1 if p % 2 == 0 else −1   ← 反号（真反对称对）
  A,B ~ N(0,1)，key = fold_in(fold_in(key, epoch), p//2)
  ΔW_p = ±(σ/√r)·A_p·B_pᵀ          ← LoRA 因式扰动（σ/√r 归一）
  fitness_p = 该样本的奖励（单样本，非批平均）
  z_p = z-score(fitness)（全局；可选 group-mean 中心化 + 全局方差）
  update = −√N · Σ_p z_p·ΔW_p / N = −Σ z·ΔW/√N → optax solver(lr)
```

关键事实（与文档印象不同处）：
1. **反对称对评估的是不同样本**（thread 2k 看样本 2k，thread 2k+1 看
   样本 2k+1，噪声反号）——**数据难度差天然混入对偶差分**。这是原始
   协议的固有属性，不是我们的迁移缺陷；它在原始库验证域（浅网）上不构成
   瓶颈，但没有理由认为它对深网络无害。
2. 更新的原始尺度含 **√N 增益**（`_do_update` 乘 √F），经 solver(lr)
   后等效 lr·Σz·ΔW/√N——与我们的 z-score/√N 逐位一致（合规 ✓）。
3. **默认 solver 是 optax.sgd**；AdamW 是用户自己的实验选择。
4. `convert_fitnesses` 支持 **group_size 组内中心化**（减组均值、除全局
   方差）——我们在 rust 中从未实现。
5. `noise_reuse` / `freeze_nonlora` / `use_batched_update` 均已合规复刻。

### 1.2 库自带的、我们未迁移的算法变体

| 变体 | 机制 | 针对 |
|---|---|---|
| `OpenES` | 全秩 dense 扰动（不做 LoRA 分解） | 对比低秩子空间假设 |
| `Sparse` | 稀疏扰动（q_multiplier） | 高维下的定向探索 |
| `EggRollBS` | **组内基线扣除**：每组前 2 个 thread 零噪声作 baseline，
  组内 z-score 除**组内**std；solver 前加 **clip_by_global_norm**（trust region） | 有噪声/episodic 的 fitness（RL 场景）；重尾奖励 |

这些变体的存在说明：**"EggRoll 单一样本 z-score 协议"只是库中五种方案之一**，
而我们此前的全部 SDT 结论都只在这一种方案下做出。

### 1.3 原始 SNN 模型（`models/snn.py`）的设计边界

原始库自带的 SNN = **2 层 FC-LIF**（90k 参数）+ Poisson 编码 + rate 读出；
`v_th=0.3`（注释明言：naive 1.0 会静默网络）；`tau_m=20`；冻结（可训练
v_th 是用户自己的追加实验）。**原始库从未在深网络/注意力/卷积上验证过 ES**——
它的成功域是浅网 + 大并行候选（用户的实验数据也支持这一点）。

## 三、多角度分析：为什么 SNN 注意力难以被 ES 积极训练

### 角度 A｜评估契约：± 对不共享样本 → 数据方差淹没深槽响应（新，最强）

**机制**。估计器实际使用的是对偶差分 Σₖ(z₂ₖ − z₂ₖ₊₁)·ε₂ₖ。当前协议下
z₂ₖ − z₂ₖ₊₁ = (响应差 + **图像难度差**)/σ_z。图像间 loglik 差 ~1–4 nats，
深槽（距读出 4–6 个非线性环节）的单方向响应 ~0.001–0.01 nats——
**信噪比常数 = 响应/数据方差，随深度指数衰减**（位点深度律的实测
0.93→0.35→0.035 正是它的参数化）。z-score 除以全局 std（被数据方差
主导）后，深槽信号被压到 ~0.1% 水平。注意：这不是 ES 的理论极限，
是**这一协议的实现选择**——经典 ES 文献（Salimans 2017 等）的 ± 对
共享同一评估上下文，数据项在差分中精确消去。

**实验**（本轮已实现 `--pair-shared`：候选 2k/2k+1 共享同一样本，
噪声 id/符号按位置语义不变）：
10ep 子集 A/B：无 QAM 11.45→**11.75**，QAM ssa 12.25→**12.65**（+0.3~0.4pp）。
方向正确、幅度温和；10ep 处 val 由 head 邻近槽主导，深槽收益需更长训练
才能显现；且共享对使每 epoch 独立样本数减半（4000），有轻微代价。
**判定：未决——需要 100ep×3 种子的对照。**

### 角度 B｜适应度整形缺失：重尾单样本奖励 + 无 clip / 无 shaping

单样本 loglik 重尾（少数图像极难/极易）；z-score 对离群敏感；库自带的
trust-region clip（EggRollBS）与组内中心化从未在 SDT 上启用。梯度更新
被少数离群候选主导的风险未量化。**判定：未决——cheap 实验：clip_by_global_norm(1.0) 臂、
group_size=50 臂。**

### 角度 C｜求解器 × 稀疏响应的相互作用

ES 梯度天然稀疏（无阈值穿越的方向响应为 0）；AdamW 的二阶矩归一化对
"信号时有时无"的坐标会放大噪声步长（v 小 → 1/√v 大）。原始库默认
**SGD**，而我们的全部结论都在 AdamW 下做出——solver 维度从未消融。
**判定：未决——cheap 实验：SGD(momentum 0.9) solver 臂。**

### 角度 D｜逐层工作点：固定全局阈值 vs 深度分化的需求

原始库自己的浅网经验（代码注释）：v_th=0.3 起步、1.0 会静默网络；
用户追加实验（非权威但自洽）：深网需要**逐层** v_th 且自然分化
（0.19/0.29/4.29）+ 10000ep + cosine。SDT 的 8 个 LIF 位点阈值固定为
全局 1.0/0.5；QAM ssa 以 m=(1+a)cos φ 给 5 个 SSA 位点提供了对偶阈值
（θ/m），但 feat/x1/x2 位点仍是全局工作点——**深网"逐层工作点分化"
的需求只被满足了 5/8**。QAM 的收敛加速（Run-3/5）与此解释自洽：
部分修复即部分收益。**判定：未决——cheap 实验：v_th 全位点可学
（E2 已有代码，需去掉 SGD 干扰单独跑纯 ES 臂）。**

### 角度 E｜σ 参考系失配：以 std(W) 为参考 vs 以穿越率为参考

σ_slot = σ·std(W_slot) 是以**权重空间**为参考；ES 信号实际由**阈值
穿越事件**驱动——正确的匹配目标是"扰动引起 ~常数比例的界面穿越"。
不同槽的（fan-in 激活 × 脉冲密度 × 阈值余量）差异极大，等 std 扰动
产生的穿越率差若干数量级。逐槽自适应 σ（等穿越率化，类似 CMA 的
坐标缩放思想）从未尝试。**判定：未决——需要先实现穿越率诊断工具。**

### 角度 F｜训练时长与搜索空间未分离

"不可积极训练"与"训练不够长"未被分离：原始库的深层配方需要 10000ep
量级；我们的纯 ES 最长 1000ep（子集）/60ep（全量）。且 Run-5 的
18.24% 是 60ep 未走完 cosine 的结果——**渐近线本身还没有被任何一次
运行真正触及**。此前的"天花板"表述应降级为"当前预算下的平台"。

## 四、结论修正声明

| 早先表述 | 修正后 |
|---|---|
| "SNN 注意力无法被 ES 有效训练"（04 文档问答） | **降级为**："在 EggRoll 单样本 z-score 协议、无适应度整形、AdamW、固定全局阈值、≤1000ep 的联合配置下未被有效训练"。五个配置维度均未单独消融 |
| "QAM 只加速不提精度" | **保留但限定**：在上述协议下成立；协议修正（A–E）后 QAM 的精度弹性未测 |
| "ES 天花板由 N/D 律决定" | **保留**（数学 + 方向数实验支持），但 N/D 的**常数因子**（响应/数据方差比）是协议可改的——这是新角度 A 的空间 |
| 位点深度律（0.93/0.35/0.035） | **保留**（协议无关的实测） |
| QAM 收敛加速 ~2×（Run-3/5） | **保留**（实测） |
| σ 衰减负结果（Run-4） | **保留**（该配置下的干净负结果） |
| 混合估计器净负（E2<E1） | **保留**（该配置下的干净负结果） |
