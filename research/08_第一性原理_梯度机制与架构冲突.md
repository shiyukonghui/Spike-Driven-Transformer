## R1 · 两种梯度场的数学对象

**真网络是分段常数映射。** 固定输入 x，spike 决策 s = 1[h > v]（h = 膜电位，
θ 的函数）把参数空间切分成有限个区域 R_α（每个 α = 一种 spike 模式），
f_θ(x) 在每个 R_α 内为常数。数据损失 L(θ) = (1/n)Σ l(f_θ(x_i)) 同为分段
常数 ⇒ **∇L = 0 a.e.，全部梯度信息集中在测度为零的决策边界上**：

$$\nabla L = \sum_i \sum_{b \in \partial_i} \Delta l_{i,b}\,\delta_{\partial R_{i,b}}\,\hat n_{i,b}$$

（Δl = 跨边界的损失跳变，n̂ = 边界法向。）两种方法都必须把这个"面测度"
转成可用的"向量场"，转法不同——这是全部冲突的源头。

## R2 · SGD 的转法：激活空间模糊（虚构景观 β<∞）

用代理 spike s̃ = σ(β(h−v)) 替换 1[h>v]，得到松弛网络 L̃_β——一个
**光滑的虚构景观**。∇L̃_β 可由链式法则精确计算，但它是 L̃_β 的梯度，
不是 L 的。收敛关系：L̃_β → L（β→∞，逐点），而 ∇L̃_β → 0 a.e.
（松弛梯度只在边界层 ~1/β 宽度内非零）。

## R3 · ES 的转法：参数空间模糊（σ>0 必须保持）

ES 估计的是高斯平滑景观的梯度：F_σ(θ) = E_ε[f_spike(θ+σε)]，

$$\hat g = \frac{1}{N\sigma}\sum_n f(\theta+\sigma\varepsilon_n)\varepsilon_n \xrightarrow{N\to\infty} \nabla F_\sigma(\theta)$$

**关键定理（ES 模糊的必要性）**：对分段常数 f，∇f = 边界面 δ 测度。
由 Green 恒等式（∇_θ φ_σ = −∇_u φ_σ 分部积分），

$$\nabla F_\sigma(\theta) = \sum_b \Delta f_b\,\big[\varphi_\sigma * \delta_{\partial R_b}\big](\theta)\,\hat n_b$$

即 **∇F_σ = 决策边界的 σ-模糊面质量**。σ→0 时 ∇F_σ 逐点 → 0 a.e.
（信号只存在于边界层宽度 ~σ 内）——**ES 的 σ 不是方差调节旋钮，而是
信号本身的存在尺度**。这与光滑景观（∇F_σ → ∇f ≠ 0）本质不同。

## R4 · 单神经元精确解：两种核的显式形式与对偶（已验证）

单 spike 神经元 y = 1[w·x − v > 0]。真景观的边界 = 超平面 {w·x = v}。
ES 平滑景观有**解析解**（σε·x ~ N(0, σ²‖x‖²)）：

$$F_\sigma(w) = \Phi\!\Big(\frac{w\cdot x - v}{\sigma\|x\|}\Big),\qquad
\nabla F_\sigma(w) = \frac{\varphi(z)}{\sigma\|x\|}x,\quad z=\frac{w\cdot x-v}{\sigma\|x\|}$$

松弛网络的 spike-概率景观（无损失权重层）：E[ỹ] = σ(β(w·x−v))，
∇ = β·s(1−s)·x——**logistic 核**（峰值常数 0.25）。

**对偶定理（已验证至机器精度）**：改用 **probit 代理** s̃ = Φ(β(h−v))，
则 ∇E[ỹ] = βφ(β(h−v))·x——与 ES 平滑核**逐位恒等**（宽度对齐条件
σ‖x‖·β = 1，max diff 4.4e-16）。即：**surrogate 的选择决定 SGD 与 ES
是否测量同一个场**——sigmoid 代理 = 同族不同形（峰值比 0.6267），
probit 代理 = 恒等对偶。损失层再各自乘权重：ES 用真损失跳变 Δl
（诚实权重），SGD 用松弛损失导数 2(ỹ−t)·s̃(1−s̃)（模糊近似）。

## R6 · 数据集版本与线性化定理（已验证，含重要修正）

数据损失 L(θ) = (1/n)Σ l(f_θ(x_i))，每样本贡献自己的边界集。σ-平滑景观
**修正（调试中发现，本身是定理）**：二值输出 y∈{0,1} 满足 y²=y，故

$$\mathbb{E}[(y-t)^2] = (1-2t)\,\mathbb{E}[y] + t^2 = (1-2t)\,\Phi(z_i) + t^2$$

**平滑损失对每个 spike 概率是线性的**——把 Φ 代回二次式 (Φ−t)² 是另一个
（均值场）函数，不是平滑景观。边界权重 = 损失跳变 Δl_i = (1−2t_i)，
回到 R1 的 δ-面测度公式。梯度 = 每样本边界核之和：

$$\nabla F_\sigma = \frac{1}{n}\sum_i (1-2t_i)\,\frac{\varphi(z_i)}{\sigma\|x_i\|}\,x_i$$

验证：ES 蒙特卡洛 rel_err 0.63%（N=4×10⁵）✅。**每样本几何权重
1/‖x_i‖**：边界锐度由样本范数决定（同范数数据集下退化为符号结构
±φ(z_i)）。

## R7 · ES 误差各向同性定理（已验证）

ES 估计误差 E[(ĝ−∇F)²] 逐坐标近似相等（实测 max/min = 2.17）：**ES 的
估计噪声在参数坐标系各向同性**——每个坐标承受同等绝对误差，弱信号
坐标被均匀淹没。对比 SGD：minibatch 噪声由样本几何结构加权，非各向
同性。这是"ES 均匀探索 vs SGD 结构化利用"差异的数学根源之一。

## R8 · 活跃集收缩定理（已验证）

梯度质量集中于 |w·x_i − v| = O(σ‖x_i‖) 的样本（活跃集）。实测前 10%
样本承载的梯度质量：σ=0.1 → 32.2%，σ=1.0 → 9.7%（均匀基线 10%）。
**σ↓ 时信号收缩到边界邻接样本**——小 σ 的 ES 实际上只从极少数样本
获取信息，与 R3 的"信号存在于 ~σ 边界层"互为表里。

## R9-R14 · AND/OR 深度定理（已验证，风格化模型）

**建模**：L 层级联，每层独立以概率 p 处于 live（膜近阈值，代理导数
显著）。SGD 代理梯度经链式法则 = 各层核**乘积**（AND：任一层 dead
则整条路径归零）：signal_SGD ~ p^L·A^L。ES fitness 对任一层翻转敏感
（并集，OR）：signal_ES ~ 1−(1−p)^L。

实测（4000 trials）：p=0.7 时 SGD 0.693→0.232→0.064→0.0047（L=1,4,8,16，
=p^L ✓），ES 0.69→0.99→1.00→1.00（=1−0.3^L ✓）；**ES/SGD 比值随 L
指数增长**（L=16 时 212×，L=32 → ∞）。

**冲突定理 C1（深度）**：代理梯度的乘性复合使 SGD 信号随深度**指数**
衰减；ES 的并集复合使 fitness 信号随深度**良态**。架构越深，ES 的相对
信息地位越好——但绝对量仍受 R3/R7/R8 的方差与活跃集限制。
