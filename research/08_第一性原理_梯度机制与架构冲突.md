## R1 · 两种梯度场的数学对象

**真网络是分段常数映射。** 固定输入 x，spike 决策 s = 1[h > v]（h = 膜电位，
θ 的函数）把参数空间切分成有限个区域 R_α（每个 α = 一种 spike 模式），
f_θ(x) 在每个 R_α 内为常数。数据损失 L(θ) = (1/n)Σ l(f_θ(x_i)) 同为分段
常数 ⇒ **∇L = 0 a.e.，全部梯度信息集中在测度为零的决策边界上**：

$$\nabla L = \sum_i \sum_{b \in \partial_i} \Delta l_{i,b}\,\delta_{\partial R_{i,b}}\,\hat n_{i,b}$$

（Δl = 跨边界的损失跳变，n̂ = 边界法向。）两种方法都必须把这个"面测度"
转成可用的"向量场"，转法不同——这是全部冲突的源头。

## R2 · SGD 的转法：激活空间模糊（虚构景观 β<∞）

用代理 spike s̃ = σ(β(h−v)) 替换 1[h>v]，得到松弛网络 L̃_β——一个
**光滑的虚构景观**。∇L̃_β 可由链式法则精确计算，但它是 L̃_β 的梯度，
不是 L 的。收敛关系：L̃_β → L（β→∞，逐点），而 ∇L̃_β → 0 a.e.
（松弛梯度只在边界层 ~1/β 宽度内非零）。

## R3 · ES 的转法：参数空间模糊（σ>0 必须保持）

ES 估计的是高斯平滑景观的梯度：F_σ(θ) = E_ε[f_spike(θ+σε)]，

$$\hat g = \frac{1}{N\sigma}\sum_n f(\theta+\sigma\varepsilon_n)\varepsilon_n \xrightarrow{N\to\infty} \nabla F_\sigma(\theta)$$

**关键定理（ES 模糊的必要性）**：对分段常数 f，∇f = 边界面 δ 测度。
由 Green 恒等式（∇_θ φ_σ = −∇_u φ_σ 分部积分），

$$\nabla F_\sigma(\theta) = \sum_b \Delta f_b\,\big[\varphi_\sigma * \delta_{\partial R_b}\big](\theta)\,\hat n_b$$

即 **∇F_σ = 决策边界的 σ-模糊面质量**。σ→0 时 ∇F_σ 逐点 → 0 a.e.
（信号只存在于边界层宽度 ~σ 内）——**ES 的 σ 不是方差调节旋钮，而是
信号本身的存在尺度**。这与光滑景观（∇F_σ → ∇f ≠ 0）本质不同。

## R4 · 单神经元精确解：两种核的显式形式与对偶（已验证）

单 spike 神经元 y = 1[w·x − v > 0]。真景观的边界 = 超平面 {w·x = v}。
ES 平滑景观有**解析解**（σε·x ~ N(0, σ²‖x‖²)）：

$$F_\sigma(w) = \Phi\!\Big(\frac{w\cdot x - v}{\sigma\|x\|}\Big),\qquad
\nabla F_\sigma(w) = \frac{\varphi(z)}{\sigma\|x\|}x,\quad z=\frac{w\cdot x-v}{\sigma\|x\|}$$

松弛网络的 spike-概率景观（无损失权重层）：E[ỹ] = σ(β(w·x−v))，
∇ = β·s(1−s)·x——**logistic 核**（峰值常数 0.25）。

**对偶定理（已验证至机器精度）**：改用 **probit 代理** s̃ = Φ(β(h−v))，
则 ∇E[ỹ] = βφ(β(h−v))·x——与 ES 平滑核**逐位恒等**（宽度对齐条件
σ‖x‖·β = 1，max diff 4.4e-16）。即：**surrogate 的选择决定 SGD 与 ES
是否测量同一个场**——sigmoid 代理 = 同族不同形（峰值比 0.6267），
probit 代理 = 恒等对偶。损失层再各自乘权重：ES 用真损失跳变 Δl
（诚实权重），SGD 用松弛损失导数 2(ỹ−t)·s̃(1−s̃)（模糊近似）。

## R6 · 数据集版本与线性化定理（已验证，含重要修正）

数据损失 L(θ) = (1/n)Σ l(f_θ(x_i))，每样本贡献自己的边界集。σ-平滑景观
**修正（调试中发现，本身是定理）**：二值输出 y∈{0,1} 满足 y²=y，故

$$\mathbb{E}[(y-t)^2] = (1-2t)\,\mathbb{E}[y] + t^2 = (1-2t)\,\Phi(z_i) + t^2$$

**平滑损失对每个 spike 概率是线性的**——把 Φ 代回二次式 (Φ−t)² 是另一个
（均值场）函数，不是平滑景观。边界权重 = 损失跳变 Δl_i = (1−2t_i)，
回到 R1 的 δ-面测度公式。梯度 = 每样本边界核之和：

$$\nabla F_\sigma = \frac{1}{n}\sum_i (1-2t_i)\,\frac{\varphi(z_i)}{\sigma\|x_i\|}\,x_i$$

验证：ES 蒙特卡洛 rel_err 0.63%（N=4×10⁵）✅。**每样本几何权重
1/‖x_i‖**：边界锐度由样本范数决定（同范数数据集下退化为符号结构
±φ(z_i)）。

## R7 · ES 误差各向同性定理（已验证）

ES 估计误差 E[(ĝ−∇F)²] 逐坐标近似相等（实测 max/min = 2.17）：**ES 的
估计噪声在参数坐标系各向同性**——每个坐标承受同等绝对误差，弱信号
坐标被均匀淹没。对比 SGD：minibatch 噪声由样本几何结构加权，非各向
同性。这是"ES 均匀探索 vs SGD 结构化利用"差异的数学根源之一。

## R8 · 活跃集收缩定理（已验证）

梯度质量集中于 |w·x_i − v| = O(σ‖x_i‖) 的样本（活跃集）。实测前 10%
样本承载的梯度质量：σ=0.1 → 32.2%，σ=1.0 → 9.7%（均匀基线 10%）。
**σ↓ 时信号收缩到边界邻接样本**——小 σ 的 ES 实际上只从极少数样本
获取信息，与 R3 的"信号存在于 ~σ 边界层"互为表里。

## R9-R14 · AND/OR 深度定理（已验证，风格化模型）

**建模**：L 层级联，每层独立以概率 p 处于 live（膜近阈值，代理导数
显著）。SGD 代理梯度经链式法则 = 各层核**乘积**（AND：任一层 dead
则整条路径归零）：signal_SGD ~ p^L·A^L。ES fitness 对任一层翻转敏感
（并集，OR）：signal_ES ~ 1−(1−p)^L。

实测（4000 trials）：p=0.7 时 SGD 0.693→0.232→0.064→0.0047（L=1,4,8,16，
=p^L ✓），ES 0.69→0.99→1.00→1.00（=1−0.3^L ✓）；**ES/SGD 比值随 L
指数增长**（L=16 时 212×，L=32 → ∞）。

**冲突定理 C1（深度）**：代理梯度的乘性复合使 SGD 信号随深度**指数**
衰减；ES 的并集复合使 fitness 信号随深度**良态**。架构越深，ES 的相对
信息地位越好——但绝对量仍受 R3/R7/R8 的方差与活跃集限制。

## R15 · 活跃分数卷积公式（已验证）

膜 h ~ N(m, s²)，核 K(d) = φ(d/w)/w（w = 算法模糊宽度：SGD 为 1/β，
ES 换算到膜空间）。高斯-高斯卷积给**解析活跃分数**：

$$p_{live}(m,v) = \frac{1}{\sqrt{w^2+s^2}}\,\varphi\!\Big(\frac{m-v}{\sqrt{w^2+s^2}}\Big)
\;\approx\; \frac{w}{s}\varphi(0)\,e^{-\frac{(m-v)^2}{2s^2}}\ (w\ll s)$$

MC 验证比值 0.9995-1.0038 ✅。**两种方法的信号都 ∝ p_live**（SGD 的
逐层核质量 = ES 的翻转概率）——膜-阈值距离是共同的信号资源。

## R16 · 自适应阈值增益定理（已验证）

m_i ~ N(0,1) 的 M 个神经元：固定最优阈值 avg_live = 0.2917，自适应
v_i = m_i → 0.3970，**增益 1.36×**。增益随膜分布展宽而增大（固定阈值
只服务分布中心）；训练漂移下固定阈值的增益衰减是动态的（R17）。

## R17 · 漂移指数衰减表（已验证）

p_live 相对增益 vs 漂移 d = m−v：实测 0.884/0.610/0.138/0.012
（d=0.5/1/2/3）——与 exp(−d²/2s²) 逐点吻合 ✅。**固定阈值下膜的
分布漂移以指数速度杀死信号**：漂移 2σ → 信号剩 14%，3σ → 1.2%。

## R18 · 深度复合塌缩（已验证）

L 层独立漂移（|N(0,1)|）：乘性信号中位数在 L=16 时比居中网络低
**1772×**（L=4: 5.4×, L=8: 41.5×）。深度把"膜漂移→死区"的指数衰减
复合成灾难——**这就是固定阈值 + 深度 SNN 在两种算法下都退化的数学
机制**，也是 QAM（可学习阈值补偿）有效性的理论解释。

## R19 · 时间通道容量定理（已验证，精确枚举）

静态编码（输入重复 T 步）：膜轨迹单调 → spike 模式 s = 1[t≥τ] 由单一
穿越时刻 τ 决定 → **可达模式恰 T+1 个**（枚举验证：T=8 时 9/9 ✅），
容量 log₂(T+1) bit。Poisson 编码：每步独立噪声 → 可达模式 255≈2^T
（枚举），容量 ~T bit。**静态重复把 T 维时间坍缩成单标量的 T 次确定性
读取——T 步前向换来 O(log T) bit；时间噪声把容量恢复为 O(T)。**

## R20 · 计数统计的内在方差（已验证）

静态：Var[C|x] = 0（C 是 (w,x) 的确定性函数——观测无随机性，平滑
Fisher 同样是分段常数的边界结构）；Poisson：Var[C] = 28.4 ≈ 3.6×T·p(1−p)
（轨迹相关导致的过散，但 ∝T 标度保持）。**时间维度的信息需要时间
维度的噪声来激活——无噪声的 T 步是浪费的算力维度。**

## R21 · 任意协方差无偏性 + 梯度能量泄漏定理（已验证）

二次景观 f = −½θᵀHθ，反对称 ES 推广到任意协方差 C = AAᵀ：
ĝ = ½[f(θ+Aε)−f(θ−Aε)]·C⁻¹Aε。差分**精确**等于 −2(Aε)ᵀHθ（无三阶项），
故 **E[ĝ] = −Hθ 对任意 C 成立**（MC 验证 0.6-1.3%）✅。方差（对角情形
解析）：

$$\mathrm{Var}[\hat g_i] = \sum_j g_j^2\,\frac{c_j}{c_i} + g_i^2 \quad(\text{MC 验证 0.56\%})$$

**梯度能量泄漏**：坐标 i 的噪声含全部坐标的信号能量 Σg_j²（经 c_j/c_i
缩放）——各向同性下弱坐标 SNR² = g_i²/‖g‖²：g=(10, 10⁻³,…) 时弱坐标
SNR² = 10⁻⁸，**弱信号被强坐标的能量泄漏淹没**（实测）✅。

## R22 · σ 分辨率定理（已验证）

**单边界 SNR 的 σ 不变性**：规范问题 f = Δf·1[u>d]（u = 扰动沿边界法向
的位移），反对称估计器 SNR² = 2φ(D)²/(φ(D)+D(1−Φ_D)−2φ²_D) 与 σ 无关
——核信号与命中概率同步缩放（MC：σ=0.3/1/3 下 0.4133 恒定）✅。
**σ 的真实角色是分辨率**：双边界相距 s 时，近/远边界贡献比
r(σ) = φ(s/σ)/φ(0)——σ≪s 分辨两边界，σ≫s 合并（信号按法向加权平均，
产生混合偏置）。**σ 应匹配边界间距的分布，而非边界距离**——这修正了
R8 的活跃集图像：σ 同时控制活跃集宽度与边界分辨率。

## R23 · z-score 保向定理（已验证）

管线中的 z-score 整形是 f 的仿射变换（经验 μ̂,σ̂ 为数据常数）：
cos(g_raw, g_z) = 1.000000，且 |g_z|/|g_raw| = 1/σ̂_f **精确成立**
（实测 18.0137 = 1/std(f)）✅。**z-score 只缩放不旋转梯度场**——
它把 fitness 的绝对尺度归一，使 AdamW 的逐坐标动态与 fitness 尺度
解耦；方向信息完全由边界结构决定。

## R24 · Fisher 形协方差等化定理（已验证）

R21 方差结构下取 **c_i ∝ 1/g_i²**：Var[ĝ_i] = (d+1)g_i² →
**SNR² ≡ 1/(d+1) 对所有坐标相等**（实测 min=max=0.05882）✅。
双块能量失衡验证：g = (5,5,5,5,0.05,…) 时各向同性 SNR² 比值 8×10³，
Fisher 形修正后 **比值 = 1.00** ✅。

## R25 · 形状匹配 ES 提案（数学结论，不训练）

综合 R21-R24 的可执行形式：**每槽扰动尺度 σ_slot ∝ 1/RMS(g_slot)**
（梯度referenced，非权重 std referenced）——这是 Adam 二阶矩归一化在
ES 侧的对偶：SGD 用 E[g²] 除更新，ES 用它定扰动协方差。廉价估计器：
(i) ES 运行内累积的每槽 z-加权贡献二阶矩；(ii) 少量代理梯度探针
（自 diff 图可用）。注意 1/g² 在死区发散 → 实用形式
σ_slot ∝ 1/√(RMS(g_slot)²+τ)（阻尼 Fisher）。**该提案不改变景观
（无偏 ∀C），只重排估计噪声的坐标分布**——与 C3（膜死区）互补：
C3 救"没信号的坐标"，R24 救"信号被泄漏淹没的坐标"。

## R26 · 突破点 1：自适应阈值 = 漂移免疫（已验证）

膜均值分布展宽 σ_m 下（w=0.1, s=0.3）：固定阈值 E[p_live] =
φ(0)/√(w²+s²+σ_m²) **精确解析**（MC 0.6748/0.3802/0.1975/0.0995 对照
✅）；自适应阈值 v_i = m_i **对 σ_m 完全平坦**（恒 1.2616）。σ_m=4 时
增益 12.7×；L=16 复合塌缩下（R18 机制）自适应阈值收益 10¹²×。
**固定阈值的深度 SNN 不是"次优"而是"塌缩"——自适应阈值是必需品而非
优化项。**（实证对照：QAM 可学习阈值 +2×、freeze +3.2pp 均为阈值
邻接杠杆——理论解释已闭环。）

## R28 · 突破点 2：边界间距匹配（已验证）

单边界的参数空间翻转概率 p_flip(σ) = Φ(−d/(σ‖a‖))（a = ∂h/∂θ，MC 与
解析全 σ 吻合 ✅），过渡中心精确在 **σ\* = d/‖a‖**——即参数空间的
边界间距由该边界的输入范数决定。**ES 的 σ 与代理宽度
σ_b = 1/(β‖a‖) 在 σ\* 处会合**——Fisher 形协方差（R24/R25）就是
"逐边界间距匹配"的可执行形式。一个旋钮，两个推导（能量泄漏等化 +
分辨率匹配）。

## R27 · 突破点 3：时间容量恢复（C4 的解，定理 + 已证伪边界）

静态编码容量 O(log T)（R19 精确枚举）——T−1 每每 T 个前向步信息死亡
是**构造性**的。时变编码恢复 O(T) 容量，但引入时间噪声（R20 过散
3.6×）。与早先 K\* 修正的关键差别：**时间复制是免费的**（T 步前向本来
就在算）——它不减少方向数 N，直接降低 fitness 的每候选测量方差。
实证边界：poisson 编码短程（1000ep MNIST）84.95 < static 87.34——
容量收益被短程噪声成本压过；理论预测长程/方差匹配速率下反转。
**状态：数学成立，实证未决（需方差匹配的 poisson 复测）。**

## R29 · 突破点 4：probit 对偶 = 双算法兼容架构（R4 推论）

probit 代理下 SGD 与 ES 测量**同一个场**（机器精度恒等，R4）→
每更新步可互换：廉价图内 SGD 步 + 少量图外 ES 步（量化诚实、无 BPTT
内存）混合训练。β-退火（最优配方 β×2/30ep）与 σ-退火由 σ‖x‖·β=1
对偶锁定——**β-退火的有效性（+0.5pp 实证）获得理论解释：它把激活
模糊宽度对齐到参数探索尺度**。
