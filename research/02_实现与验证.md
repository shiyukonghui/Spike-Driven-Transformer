# 02 · 实现与验证

代码：`rust-sdt/`（burn 0.21 / wgpu-fusion，单 crate）。权威细节见
`rust-sdt/ES_MANIFOLD_NOTE.md` 与 `rust-sdt/check_log.txt` 十一~十五节。

## 1. ES 训练架构（factored 模式）

- **槽位化参数**：blocks 6×1×1 conv（q/k/v/proj/fc1/fc2）+ head，共 13 个
  lora 槽（权重走因式 LoRA 噪声）+ 13 个 dense 槽（偏置走加性噪声）；
  SPS（~765k 参数）冻结——ES 预算不给深槽（位点深度律）。
- **确定性噪声**：种子化 Box-Muller + murmur3 fmix32 雪崩（S3 修正
  GF(2)-线性 xorshift 的配对偏置）；反对称对共享随机流，pop=n_train 时
  ΣΔW ≡ 0（M1 精确性）。
- **逐图候选前向**（es_forward_factored）：候选并入 batch 维，chunk=128/256；
  S2 用 one-hot matmul 行选择替代 CPU gather；全局 z-score + 单次 AdamW。
- **S1–S9 优化清单**（详见 check_log 十二节）：GPU 累积统计、β 退火
  hard-switch opt-in（S4 后默认全程松弛）、relax-scope、行选择、
  slice_assign、批同步策略等——单 epoch 5.4s（pop=8000）。

## 2. QAM 调制（commit d35a972 数学 / 65fb23d 实现）

- **方程**：m = (1+a)·cos(φ) 乘在 LIF 输入电流上（位点 id：0=xs 1=q 2=k
  3=v 4=kv 5=x1 6=x2 7=feat；神经元数 256，x2=1024）；m 按位点类型跨
  block 共享；恒等起步 init a=0.1, φ=0.5（m≈0.966）。
- **ES 集成零改动**：QAM 槽 = 1-D dense 噪声槽（FLoc::Qam(site, which)），
  复用 z-score/反对称/AdamW 全套估计器（M1 精确性保持）。
- **σ_slot 固定尺度**：c_a=0.1、c_φ=0.5 × σ——槽初始近常数，std 口径
  会退化为 0（Run-4 再证：不要与 lr 耦合衰减）。
- **eval 路径**：`forward_full` 穿线 `Option<&QamWeights>`，验证 = 硬前向 +
  调制（部署二值脉冲语义不变）；速度与基线持平（逐元素乘）。
- **CLI**：`--qam off|learnable`，`--qam-sites head|ssa|all`。

## 3. 混合估计器（commit e186a78）

- **分工**：SGD（momentum 0.9，精确梯度，CrossEntropyLoss + STE）管全部
  W/b+SPS（~2.56M 参数）；ES 只管 v_th（8 位点标量，σ_vth=0.2σ）+
  QAM (a,φ) 槽。
- **关键机制——逐候选阈值**：v_th 的 ES 一阶信号要求阈值逐候选不同
  （θ_c = θ + δ_c）；新增 `ops::lif_seq_bth` 张量阈值 LIF（硬 + 松弛），
  阈值张量 [1,C,1,1,1] 广播。
- **交替结构**：每 epoch = 1 个 SGD epoch（前向携带当前 m/v_th，
  `QamWeights` 扩展 vth 字段）+ 1 次 ES 更新（W/b 零噪声 fitness，
  z-score + AdamW(lr 0.02, **wd=0**——零梯度槽不衰减；m/v 必须覆盖
  全部槽与 es_params 1:1 对齐））。
- **CLI**：`train-mixed`。

## 4. 工程教训（burn 0.21 / Windows）

- PowerShell Get-Content|Set-Content 往返会把 LF→CRLF 污染 diff——
  编辑一律用 edit 工具；
- `Tensor::from_floats` 的类型标注必须与输入可推断形状同秩（flat slice
  → rank-1，再 reshape）；
- sum_dim 保留维（feat 实为 rank-4 [T,C,ch,1]）——广播 reshape 按此算；
- autodiff 权重与 inner 后端互转：`to_autodiff_weights`/`to_wgpu_weights`
  （`Tensor::from_inner` / `.inner()`）；eval 必须走 inner 后端
  （autodiff 前向图节点无 backward 消费时钉死显存）；
- 数据路径回退链：`{data_dir}/cifar10_data.npz` → `artifacts/cifar10_data.npz`。
