# ES × 脉冲注意力：流形结构、平滑等价与温度松弛模拟方案

> 目的：为「ES 训练 SDT 失败、标准 SNN 成功（0.9149）、注意力 SNN 中等（0.58）」的现象建立
> 第一性原理的数学解释，并给出可实现的模拟方案（TSES：温度松弛 ES）。
> 定理骨架与 es_batch_equivalence_math.md 的「小批次等效大批次」同一风格：
> 先给精确恒等式，再给可操作推论。
>
> 事实基线（HyperscaleES docs / 本仓库实测）：
> | 配置 | 精度 | 备注 |
> |---|---|---|
> | 标准 SNN（2 层 LIF，117k 参数，trainable v_th）+ ES 累积 | **0.9149** | 3000 ep × batch 60000，墙钟 413s |
> | Hopfield 连续注意力 SNN + ES 累积 | 0.58 | 同预算，注意力核心无硬阈值 |
> | Mean-field 软阈值注意力 SNN + ES 累积 | 0.55 | cos_o 一度跌到 0.6 |
> | SDT（硬脉冲 SSA，2.56M 参数）+ ES（本仓库） | 0.1768 | 100 updates（v3 全量 34 ep 终止） |
> | SDT + SGD(STE α=4) | 0.6555 | 25600 updates |

## 0. 记号

- 脉冲网络 f(x;θ)：仿射/卷积层 A_l 与阈值读出交替；LIF 的膜积分是**线性**的
  （跨时间可并入 A_l），唯一非线性是阈值读出 u = H(h − τ)，h 为阈前电位。
- θ ∈ ℝ^D（D≈2.56e6，不含 head 约 1.58e6 可训练）；fitness F(θ) = 𝔼_𝒟[ℓ(f(x;θ), y)]。
- ES 估计量（八/九节已实现）：ĝ = −(Σ_n s_n ΔW_n − mean·Σ_n ΔW_n)/(std·√N)，
  s_n 为 z-score 后 fitness，ΔW_n 为第 n 个噪声方向的实际扰动。

## 1. 定义（切换复形与流形分层）

对每个阈值位点 i（层×通道×token×t 共 M 个），定义**切换超平面**
  Σ_i = { θ : h_i(θ) = τ_i }
（h_i 对上游权重线性）。切换复形 𝒜 = ∪_{i=1}^{M} Σ_i 把参数空间 ℝ^D 分割成开胞
{𝒞_α}；在每个胞内发放模式 s(θ) ∈ {0,1}^M 恒定。

## 2. 引理 1（胞内平坦性——SDT 的梯度只活在测度零集合上）

**断言**：在任一开胞内，
  ∇_θ F = (∂F/∂head_w, ∂F/∂head_b, 0, …, 0)。

**证明**：胞内 s 冻结。SDT 的前向以 head_lif 的阈值输出为最后一级非线性：
logits = head_w·feat_spike + head_b，而 feat_spike 在胞内是冻结常数 ⇒
logits 仅随 (head_w, head_b) 变化。任何更上游权重 W 的胞内变化只改变阈前电位
（被其下游的第一个阈值截断），不影响冻结的 s ⇒ F 不变。∎

（逐槽核对：q/k/v 的输出经 LIF 阈值后才进入乘性注意力；proj/fc1/fc2 的输出经
残差相加后立刻进入下一级 LIF——残差不消除截断，因为恒等支路上的张量同样是
冻结脉冲或其线性像。SPS 同理且已被冻结。）

**推论 1.1（平板流形）**：真硬脉冲网络的 F 在 ℝ^D 上几乎处处为常数（head 除外）。
SGD 无 surrogate 时梯度恒零（经典 SNN 死亡梯度）；**ES 的全部信号必然来自切换复形
上的跳变**——数学上等价于对 M 个 Bernoulli 潜变量 s_i 的 REINFORCE：
advantage ↦ J_i（翻转位点 i 引起的 fitness 跳变），策略梯度 ↦ φ_σ(h_i−τ_i)∇h_i。

## 3. 定理 1（ES = 高斯平滑景观上的精确梯度流）

F_σ(θ) ≡ 𝔼_ε F(θ + σε)，ε ~ 𝒩(0, I_D)。Stein/Nesterov 恒等式：
  ∇F_σ(θ) = 𝔼[ F(θ+σε)·ε ] / σ²。
z-score 是对 F 的仿射重标，不改变梯度方向（八节仿射引理）。频域：
  F̂_σ(k) = F̂(k)·e^{−σ²‖k‖²/2}，
即 **ES 优化的是波长 ≳ σ 的地形**；σ 的物理意义 = 权重空间的探索尺度，
其最优值应匹配切换复形的间距（实测 σ_rel=0.5 最优、1.0 破坏 = 裕度尺度的经验证据）。

## 4. 定理 2（接口分解：信号与两级方差灾难）

对分片常数 F（引理 1），由余面积公式/Gauss–Green，平滑景观的梯度分解为
  ∇F_σ(θ) = Σ_i 𝔼[ J_i(θ) · φ_σ(h_i(θ)−τ_i) · ∇h_i(θ) ] + ∇head 项，
其中 J_i = F 在 Σ_i 法向两侧的跳变（= 翻转该脉冲的 fitness 效果），φ_σ = 高斯抹平的
Dirac（≈ N(0, σ²) 密度）。三点推论：

**4.1（信号通道 = REINFORCE）** ES 能学的全部内容 = 「哪些脉冲翻转在统计上有利」。
这对 2 层网络可行（他们的 0.9149），对 20+ 层网络被两级方差灾难压垮：

**4.2（方差灾难一：级联复合）** 单个上游脉冲翻转以概率 p 波及 fan_out 个下游阈前
电位，各有随机符号的跳变 J̄，并继续向下游级联。一阶分支近似：
  Var[f'] ≈ J̄² · Σ_{ℓ=0}^{L′} (p·fan_out·κ)^ℓ ≈ J̄² · ((p·fan_out·κ)^{L′} − 1)/(p·fan_out·κ − 1)
对下游深度 L′ **几何增长**。标准 SNN 的 L′ ≈ 2（且读出是速率平均=线性平滑器），
SDT 的 L′ ≈ 20+（且中间是乘性注意力）——这一项就是 0.91 与 0.17 的主骨架之一。

**4.3（方差灾难二：乘性零因子阻断 + 广播放大）** SSA 读出 y = s_q ⊙ s_kv（对 64 token
广播）。∂y/∂h_{kv} ∝ s_q：任一 cofactor 为 0 则该位点接口信号为零（阻断），活位点
比例 ~ Π(发放率) 指数小；而活位点的翻转经 64-token 广播把 J 放大（符号随机）→
方差 ×64。**乘性注意力同时缩小信号承载集、放大跳变幅度**——解释了为什么
「难点在注意力」而不在卷积/MLP 部分。

**4.4（速率律：N/D 定律）** ĝ 的角度误差 𝔼‖ĝ − ∇F_σ‖² ≈ (κD/N)·‖∇F_σ‖²
（κ = 单方向 fitness 噪声/信号比），每次更新的有效进步因子 ≈ N/(N + κD)。
- 标准 SNN：N/D = 60000/1.17e5 ≈ **0.51**
- SDT：N/D = 50000/1.58e6 ≈ **0.032**（16× 劣势），且 updates 少 30 倍（100 vs 3000）
→ 总进度劣势 ~500×。0.91 vs 0.17 的定量骨架 = 4.2 + 4.3 + 4.4 三项相乘。
v1→v2→v3 的 +1pp 级增益 = 纯 1/N 的 Monte-Carlo 方差下降，边际递减与实测一致。

## 5. 定理 3（温度松弛等价 + 退火边界）——模拟方案的数学基础

**3.1（松弛 = 阈值噪声的精确期望）** 取独立阈值噪声 ξ_i ~ Logistic(0, 1/β)：
  𝔼_ξ[ 1[h_i + ξ_i ≥ τ_i] ] = σ(β(h_i − τ_i)) ≡ s_β,i
sigmoid 读出 = 带 hot 阈值噪声的硬脉冲的**精确期望**（非近似；物理对应 = SNN 硬件
的膜电位噪声，因此松弛训练的副产品是阈值噪声鲁棒的权重）。

**3.2（STE 恒等）** ∂s_β/∂h = β·σ(1−σ)。于是松弛网络的解析梯度
  ∇F_β = 标准 STE 代理链式法则（α=β），
**处处非零**（引理 1 的平坦胞被松弛"抬出斜率"）。⇒ SGD+STE(α=4) = 对 F_{β=4} 的
逐样本精确梯度；ES = 同一 F_β 的方向空间 Monte-Carlo。**二者是同一平滑目标的双
估计器**：SGD 方差 = 批噪声（逐样本精确），ES 方差 ∝ κD/N。这从数学上统一了
「STE 为什么对 SGD 有效」与「ES 需要连续松弛」——同一个 mollifier 族。

**3.3（退火边界 / margin 定理）** |σ(βx) − 1[x≥0]| ≤ e^{−β|x|}，故
  |F_β(θ) − F(θ)| ≤ Σ_i 𝔼[ e^{−β·m_i} · |𝔡_i| ]，m_i = |h_i − τ_i|（脉冲裕度）。
硬化的代价完全由**阈前裕度分布**控制。定义可实测的接口质量
  ρ(β) = (1/M)·|{ i : |m_i| < c/β }|。
**退火判据：仅当 ρ(β) ≤ ρ* 时才升 β**；若终点 hard-drop 超容忍 → 冻结 + SGD 微调。

## 6. 模拟方案 TSES（温度松弛 ES）——方程组

每个 generation：
1. **松弛前向**：膜积分不变（线性）；LIF 读出换成 s = σ(β(h − v_th))
   （最小改动：只松弛 SSA 的 kv-LIF 与 q/k/v 读出；保守：全部 LIF 读出）。
2. **fitness**：f_n = ℓ(f_β(x_n;θ), y_n)；z-score 仿射修正不变（八节）。
3. **更新**：AdamW(ĝ)，ĝ = −(Σ raw·ΔW − mean·ΣΔW)/(std·√N_L)；此时 ΔW 可取小 σ
   （胞内斜率存在，不再依赖大 σ 翻转脉冲）。
4. **温度调度**：β_0 = 4（= spikingjelly STE α=4 的已知可学平滑度）；每 epoch 实测
   ρ_t，ρ_t ≤ ρ* 时 β ← 1.2β；σ 取实测裕度分位数（margin-matched σ）。
5. **收官**：β_max 下硬前向验收；hard-drop 超容忍则 SGD 微调或回退 β。

**可证伪预测**：
- P1：松弛后 block 权重的梯度范数非零（1 个 batch 的 A/B 实验：硬前向 STE 范数 ≈ 0
  vs 松弛前向 ∇F_β 范数 > 0——引理 1 + 定理 3.2 的直接检验，成本 ~1 分钟）；
- P2：同预算（100 updates）v4 显著超过 17.68%（上界仍受 4.4 速率律与更新数限制）；
- P3：硬化损失可由 ρ(β) 直方图预测。

## 7. 速度问题的数学回答（为什么 34 epoch / 5067s）

成本模型（实测系数）：
  T_ES(epoch) = N_L·c_fwd + n_chunk·c_sync + n_test·c_eval + c_opt
             = 50000×1.4ms + 195×~0.2s + 10000×~1.5ms + ~5s ≈ 149s
  T_SGD(epoch) = (N/b)·c_step + eval ≈ 1563×74ms + 14s ≈ 129s
→ **每 epoch 墙钟二者相当**；慢的是单位更新成本：ES = 149s/更新（每 epoch 1 次），
SGD = 82ms/更新（每 epoch 1563 次），比值 ~1800×。
而定理 2.4 的速率律要求 updates ≳ (κD/N)·log(1/ε)。他们的 91%：3000 updates ×
0.138s/epoch（2 层 MLP 每样本前向 ~10μs，JAX vmap）= 413s；SDT 同样 3000 updates =
3000 × 149s ≈ **5.2 天**（逐项优化 c_sync/eval/大 chunk 后 ~2.5 天）。
**慢的数学本质 = 单位更新成本（N_L 次前向 × 模型单价）× 所需更新数（∝ D/N_L），
两个因子都随「模型前向单价 × 参数维」增长**——他们的小 MLP 两头都小，我们的
卷积 SNN 两头都大；这与算法实现质量无关。

## 8. 结论

1. 引理 1：SDT 硬脉冲景观是平板流形，梯度全在切换复形上 ⇒ ES ≙ 深层 Bernoulli
   REINFORCE，方差随深度与乘性扇出几何爆炸（定理 2）——这是「难点在注意力」的
   数学形式，且解释了 0.91（浅、无线性外无阈值、trainable v_th）↔ 0.58（连续注意力）
   ↔ 0.17（硬脉冲注意力 + 1/30 更新数）的全部阶梯。
2. 定理 3 给出修复的精确形式：sigmoid 读出 = 阈值噪声期望 = STE 的 mollifier——
   **松弛不是妥协，而是把训练从测度零的接口上搬回开胞**；β 退火 + margin 判据
   保证硬化可控。
3. 实施优先级：P1 平坦性 A/B（1 分钟）→ TSES 最小实现（只松弛 SSA 两个 LIF 读出）
   → 100 updates 对照 → 若斜率确立，再谈预算（500-3000 updates）与 ES/SGD 混合
   估计器（平滑权重用 SGD、离散自由度 v_th/β 用 ES——各取其估计方差最小者）。

## 9. 数值验证（真实 CIFAR-10 + mini-SDT 复刻，scripts/verify_es_math.py，2026-09-09）

环境：torch 2.0.1+cu118 / RTX 4090；真实数据 8000 训练/2000 测试（RandomState(42)
同 rust 侧规则）；mini-SDT 忠实复刻结构（stem + 2×LIF-SSA block（q⊙kv 线性注意力、
LIF(1.0)/LIF(0.5)）+ LIF head，T=2，d=32，~9 万参数，静态校准 mem std=1.0）。

### 9.1 恒等式（A 部分，全 PASS）

|---|---|---|
| A1a Stein 恒等式（二次型，MC 1e7） | cos = 0.99951 | PASS |
| A1b Stein（tanh-MLP，ES 4e6 vs 平滑景观 CRN 有限差分 1e6） | cos = 1.0000 | PASS |

| A3 裕度界 \|σ(βx)−H(x)\| ≤ e^(−β\|x\|)（2001 点） | 最大违反 1.08e-16 | PASS |

### 9.2 引理 1 胞内平坦性（B 部分，真实数据 batch=16，全 PASS）
| 参数 | 胞内 η/std | 胞内 ΔF | 跨胞 η/std | 跳变 ΔF | 松弛 ΔF(同 η) |
|---|---|---|---|---|---|

*首次翻转即越过接口，但该脉冲翻转未波及 head-LIF → logits 不变（"厚板"效应：
需翻转直达读出的位点才产生跳变——比引理 1 更强的平坦性）。松弛网络在同一胞内
η 下所有 block 权重出现 ~2e-2 的斜率——**斜率被松弛抬出**，定理 3.2 前提成立。

### 9.3 信号通道（C 部分，真实数据，N=256，σ_rel=0.5）
- cos(g_松弛解析, g_STE) = **+0.8986**（双估计器同一 mollified 目标；<1 因连续 reset
  与硬 reset 的膜轨迹差异）；
- **全空间 ES 余弦 ≈ 0（hard −0.008 / relaxed −0.005）**——D≈9 万 vs N=256，角度误差
  ~√(D/N)≈19：**定理 2.4 的 N/D 速率律现场演示**（估计量被 MC 噪声淹没，与松弛
  与否无关）；
- 逐层方差剖面（N=512）：hard/relaxed 的 Var[Δfitness] 比 = qkv-l0 **13.6×**、
  qkv-l1 **8.2×**、fc/proj-l1 **13.9×**、head **1.2×**——block 权重跳变主导（定理 2），
  head 平滑——与引理 1 的"仅 head 胞内活跃"精确对应。

### 9.4 子空间一致性（C2，D_eff=64 ≪ N， fitness-上升符号约定）
| N | cos(ES_hard, STE) | cos(ES_relax, STE) | cos(ES_relax, 解析) |
|---|---|---|---|
| 256 | 0.0951 | 0.7703 | 0.9052 |
| 4096 | 0.0342 | 0.7946 | **0.9924** |

**松弛化 ES 是解析梯度的一致估计器（|cos|→0.99），硬脉冲 ES 无信号（0.03-0.10，
不收敛）**——引理 1 与定理 3 的直接数值证明。

### 9.5 真实训练对照（D 部分，300 generation，N=256，es_batch=8，AdamW lr 0.02）
| 方案 | val top-1（2000 测试） | 轨迹 |
|---|---|---|
| SGD-STE（600 步） | **30.35%** | 22.05→24.55→30.35 稳定上升 |
| ES-hard | 13.75% | 峰值 17.40%@gen100 后回落 |
| ES-relax β=4 | 11.50% | 峰值 14.55%@gen100 后回落 |
| ES-relax 退火(β 4→16) | 12.45% | 峰值 19.05%@gen200（β=16）后回落 |

解读（诚实口径）：N/D ≈ 256/9e4 ≈ 0.003 时，**预算而非信号通道是约束**——三个 ES
变体都先学后衰（MC 噪声主导的权重随机游走），松弛化的收益（C2 已证信号存在）
在这个预算下无法兑现。SGD 以 ~1/3 的墙钟到 30.35%。这与 rust 全尺度 v1/v2/v3
（N/D 0.005-0.032，平台 15.7-17.7%）外部一致。

### 9.6 验证结论（优化方向的数学基础，全部有真实数字支撑）
1. **引理 1 成立**：硬脉冲网络 = 平板流形，ES 信号 ≈ 0（cos 0.03-0.10，不随 N 收敛）；
2. **定理 3 成立**：sigmoid 松弛 = 阈值噪声期望 = STE 同族 mollifier；松弛化后 ES 是
   解析梯度的一致估计器（0.905→0.992）；
3. **定理 2.4 成立**：全空间 ES 在 N≪D 时被 MC 噪声淹没（cos≈0），速率 ∝ N/D——
   v1→v2→v3 的 +1pp 边际递减与 D 部分的平台由此定量解释；
4. **优化方向**（按数学必要性排序）：① 松弛化（TSES）——信号存在的必要条件，
   已证；② 预算或混合估计器——SGD 管平滑权重（D 部分：同墙钟 2.2 倍精度），
   ES 只管 v_th/β 等低维离散自由度（其子空间 D_eff 小，N/D 大，信号可提取）；
   ③ 单纯加大方向数（v1→v3 路线）在引理 1 的平板流形上无信号可提取，已被证伪。

（预算约束仍在）——下一步是混合估计器（SGD 管平滑权重 / ES 管 v_th/β），
而非继续调 ES 超参。

## 11. 全链路软件优化 + 1000 epoch 可变学习率验证（2026-09-09，check_log 十二节）

数学结论（§1-§10）不动，本节记录把「每 epoch 成本」压下来的工程项与终局验证。
优化节点逐项 git 提交（main 9e678ee…b65a252），每节点 10ep A/B 或逐位一致性验证：

| 节点 | 内容 | 实测 |
|---|---|---|
| S1 | raw 统计/正确数全程 GPU 累积（删 124 次 into_scalar 同步） | fwd 13.7→6.1s |
| S2 | 训练集预载显存 + GPU one-hot matmul 行选择（f32 逐位精确） | fwd 6.1→5.3s |
| S7 | fitness 改 gather（去 one_hot 构造+乘法） | 与乘法 1ulp 一致 |

| S8 | lif_seq 预分配 + slice_assign 写回（去 Vec+cat） | 数值一致 |

| S3 | 噪声因子 GPU 端生成（xorshift32+Box-Muller 全向量化） | fwd 5.3→2.7s |

| LR | 线性 warmup + 余弦退火（--lr-warmup / --lr-min-frac） | 1000ep 用 25/0.1 |

S3 的关键教训：xorshift 是 GF(2) 线性映射，弱 elem 混合（elem 与 elem+half 仅差
常数 XOR）使 Box-Muller 两半确定性相关 → 法向分布系统偏差 → fitness 崩至 −10。
修复 = murmur3 fmix32 雪崩；numpy 逐位复刻验证。**数学指导的结论再一次成立：
伪随机流的「独立性」是估计器的生命线，混合不足的流等价于有偏采样。**

M2 负结果的理论解释：同图反对称对把 pair 差分的图像难度噪声（±2-4 nats）消除，
方差严格下降——但同时把每更新的独立图像覆盖从 8000 砍到 4000。在 100-update
预算下，梯度质量由数据覆盖主导（ES 每 epoch 仅一次更新，无小批量平均机会），
覆盖损失压倒方差收益。该优化在 per-update 全批口径（迁移版 batch=60000）下
依然成立，不成立的是「逐图 es_batch=1」口径。

1000 epoch 终局验证（Run-1 vs Run-2，各 94 分钟）：

| 方案 | best_val | 终点 val | 终点-峰值 |
|---|---|---|---|
| v4 100ep（松弛，恒定 lr） | 17.10% | 17.10% | 0 |
| Run-1 1000ep（ep50 切硬 [S4]） | 16.20%（ep136） | 13.85% | −2.35pp |
| **Run-2 1000ep（全程松弛 + lr 调度）** | **17.30%** | **16.95%** | **−0.35pp** |

1. **Run-2 = 新纪录 17.30%**：每 epoch 24.1s→5.6s（4.3×）的软件优化直接兑换成
   10× 更新预算；warmup 25ep + 余弦退火至 0.1×lr 把尾段稳在峰值附近
   （终点−峰值仅 0.35pp，Run-1 为 −2.35pp）。
2. Run-1 复现了 v2 式衰减——机制正是定理 2/3：σ(16·) 的 fitness 值虽≈阶跃，
   但硬 LIF 的 ES 信号只在切换复形上，松弛把训练搬回开胞的结论不可妥协。
   S4 已改为 opt-in（--hard-at-16）。
3. M2（同图反对称对）实测为负优化（覆盖度 8000→4000 压倒配对方差收益），
   已回退存档——ES 每 epoch 仅一次更新、无小批量平均，数据覆盖主导梯度质量。
4. 两个被实测否决的"优化"与三个被逐位/A/B 验证的优化共同说明：**这条数学
   路线上，"信号通道是否开放"与"伪随机流是否独立"是仅有的两个生死判据**，
   其余皆为常量因子。下一步仍是混合估计器（SGD 5ep = 58.95% 的差距是预算
   量级，见 §9），而非继续调 ES 超参。

## 12. QAM 调制 ES：方程引入与优化（2026-09-09，check_log 十三节）

来源：`H:\snn-thinking\agid\qam-snn`（正交幅度调制 SNN）。核心思想：在 LIF 的
输入电流上乘一个每神经元的（可学习）调制因子，让同一脉冲模式携带更多信息。

### 12.1 源方程（三种形态，忠实于源码）

| 形态 | 方程 | 参数/神经元 | 源码位置 |
|---|---|---|---|
| learnable（静态） | m_i = (1+a_i)·cos(φ_i) | 2（init a=0.1, φ=0.5 → m≈0.966） | five_mode.py L117 |
| complex（静态） | m_i = (1+tanh(da_i))·cos(σ(dphi_i)·π) | 2（init da=0.1, dphi=0.5 → m≈−0.42） | five_mode.py L111 |
| learnable-time | m_i(t) = (1+a_i)·cos(φ_i + sin(2π·ν_i·t/T)) | 3（t∈[0,T)） | ultra L119 |
| dy 载波 | c_i(t) = mag_i·cos(angle_i + 2π f_i t·dt)，**加**到电流 | 3 | dy L232,316 |

应用点统一为 `I_mod = I ⊙ m`（电流缩放，LIF 之前）。源项目消融
（records01.md，MNIST）：real 0.5556 / amp_only 0.9455 / complex 0.9609 /
**phase_only 0.9630**——相位是主导项，幅度次要；固定参数版（fixed_mod
0.84）次之，说明收益来自"可学习"而非"调制"本身。

### 12.2 命题 5（增益-阈值对偶）：QAM ≡ 可学习阈值的平滑重参数化

对 m_i > 0：

  硬脉冲：LIF(m_i·u, θ) ≡ LIF(u, θ/m_i) **精确**（[mu>θ] ⇔ [u>θ/m]，数值验证差=0）。
  松弛读出：σ(β(m·u−θ)) = σ(βm·(u−θ/m))——对偶伴随**温度耦合 β→β·m**。

即松弛域下 QAM 增益同时扮演两个角色：每神经元阈值 θ_i = θ/m_i 与每神经元
STE 温度 α_i = β·m_i（阈值噪声 Logistic(0, 1/(βm_i)) 的宽度）。这不是缺陷：
它把 §10 的路线判断（"ES 只管 v_th/β 低维自由度"）落到一个连续坐标上——
阈值本身在平板流形上是不可微的界面参数，而 (a_i, φ_i) 是 (θ_i, α_i) 的
平滑重参数化（m→0⁺ ⇒ θ_i→∞ 神经元沉默且噪声无限宽；m<0 ⇒ 极性翻转，
即 W 行符号对称的一个一维拨盘）。

### 12.3 命题 6（m 槽的景观秩）：连续参数化 + 位点深度律

∂f/∂m_i 在 m_i ≠ 0 处几乎处处非零——电流缩放连续改变界面穿过率，**m 槽不在
平板流形上**（对比：W 槽的信号被引理 1 限制在切换复形上）。

数值验证（scripts/verify_qam_math.py c2，2 层 LIF-MLP，松弛 β=4，ES 192 对）：

| 扰动槽 | 位置 | ES 信号 |cos| |
|---|---|---|
| W (w1) | 第一层 | 0.035–0.040 |
| W (w2) | 第二层 | 0.24–0.35 |
| m (a/phi) | 第一层 LIF 输入 | 0.065–0.072 |
| **m (a2/phi2)** | **第二层 LIF（紧邻读出）** | **0.908–0.940** |

解读：**位点深度律**——ES 信号余弦由「扰动位点与读出之间的非线性深度」主导，
槽类型（W vs m）是次要因子。m 槽的真实优势有二：(a) 连续参数化（扰动处处
有一阶响应，无平板流形的测度零限制）；(b) **紧邻读出的 m 槽信号≈1**——
这是纯增益、零级联的 ES 目标，性价比最高。SDT 中对应位点 = feat（head LIF，
紧邻 head 线性读出），其次 kv/x2，再次 SSA 前排（xs/q/k/v）。
实现按此优先级排序：--qam-sites head（默认）| ssa | all。

ES 估计器整合（零改动）：m 槽作为 1-D dense 噪声槽（±σ·ε）进 params2d，
σ_slot/z-score/反对称/AdamW 全复用；M1 精确性保持（dense ± 噪声 ΣΔm=0）。
注意：QAM 槽初始近常数（std≈0），σ_slot 不能用 std 口径（会退化为 0），
改用固定尺度 σ·c（c_a = 0.1，c_φ = 0.5，与 tanh/斜率敏感度同量纲）。

参数量（complex，全 8 位点）：2·(256·7+1024) = 5632（占 1.58M 的 0.36%）；
head 单位点仅 512（0.03%）——按位点深度律，这 512 个参数承载了最高的
单位参数信号。

### 12.4 命题 7（时间相位与 T 压缩）

SDT 静态帧重复（每 t 同一输入）使 LIF 输入时间退化；m_i(t) 的时间相位
sin(2πν_i t/T) 打破退化，让早期/晚期时间步承担不同角色。**T 压缩假设**：
QAM 下 T=2 的 fitness 信息量 ≥ 无 QAM 的 T=4 → ES 前向时间减半。
验证次序：先 T=4 验证 m 槽本身有正收益（10ep A/B），再做 T=2 压缩实验。
（部署语义不变：m 是实权重，脉冲仍是二值；验证口径 = 硬前向 + m 调制，
与训练共用同一模型定义。）

### 12.5 初始化的偏离说明（相对源码）

源码 complex 模式 init（da=0.1, dphi=0.5 → m≈−0.42）是为从头训练设计的；
SDT 从预训练权重出发，要求 m ≈ 1（恒等）起步以免一开始就破坏已校准的
前向。故 SDT 侧 learnable 模式 init a=0.1, φ=0.5（m≈0.966，接近恒等且
∂m/∂φ = −(1+a)sin φ ≠ 0，ES 一阶敏感）；complex 模式 init da=0, dphi=−4
（m≈0.998）。（cos 在 φ=0 处一阶导为零——这正是源码用 σ(dphi)·π 把相位
推离 0 的原因；我们的 learnable init φ=0.5 同样避开了一阶盲区。）
